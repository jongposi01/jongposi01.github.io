개인정보처리방침

시행일 및 최종 수정일: 2026년 8월 24일

가벼운 시트 비교기(이하 “앱”)는 사용자의 개인정보와 파일 내용을 개발자가 운영하는 서버에 수집하거나 전송하지 않습니다.

1. 수집하는 개인정보

앱은 이름, 이메일 주소, 연락처, 위치정보, 기기 식별정보 등의 개인정보를 직접 수집하지 않습니다.

2. 파일 접근 및 처리

앱은 사용자가 직접 선택하거나 끌어다 놓은 CSV, XLSX 및 XLSM 파일에만 접근합니다.

  • 선택한 파일은 비교, 표시, 편집 및 저장 기능을 제공하기 위해 사용자의 Windows 기기에서 처리됩니다.
  • 파일 내용, 파일 이름 및 비교 결과는 개발자 또는 개발자가 운영하는 서버로 전송되지 않습니다.
  • 사용자가 저장 기능을 실행한 경우에만 사용자가 선택한 위치에 수정된 Excel 파일이 생성됩니다.

3. 네트워크 및 Microsoft Store 서비스

앱의 파일 비교 기능은 인터넷 연결을 필요로 하지 않습니다. 다만 체험판, 라이선스 또는 구매 상태를 확인하고 구매 페이지를 표시하기 위해 Microsoft Store 서비스와 통신할 수 있습니다. 이 과정은 Microsoft가 제공하는 Store 기능을 통해 이루어지며, 앱은 사용자가 연 파일의 내용이나 비교 결과를 Microsoft Store에 전송하지 않습니다.

Microsoft의 정보 처리 방식은 Microsoft 개인정보처리방침의 적용을 받습니다.

4. 개인정보의 제3자 제공 및 위탁

앱은 사용자의 개인정보나 파일 데이터를 판매하거나 제3자에게 제공 또는 처리 위탁하지 않습니다.

5. 개인정보의 보유 및 삭제

앱은 개인정보를 수집하지 않으므로 개발자가 보유하거나 삭제할 개인정보가 없습니다. 사용자가 앱을 통해 저장한 파일은 사용자가 지정한 기기에 남으며, 해당 파일은 사용자가 직접 관리하고 삭제할 수 있습니다.

6. 아동의 개인정보

앱은 아동을 포함한 사용자의 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보처리방침의 변경

앱의 기능이나 관련 법령이 변경되는 경우 이 방침을 수정할 수 있습니다. 중요한 변경 사항이 있는 경우 이 페이지의 최종 수정일을 갱신하여 안내합니다.
